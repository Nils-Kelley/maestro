# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, criticise the work and not the person, and no harassment of any kind. This applies in
issues, pull requests and anywhere else the project is discussed.

To report a problem, use GitHub's "Report content" on the comment or issue concerned, or contact the maintainer privately
through the [Security tab](https://github.com/Nils-Kelley/maestro/security). Reports are kept confidential.
