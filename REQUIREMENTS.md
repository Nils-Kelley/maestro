# Requirements

| ID | Requirement | Milestone | Status |
|----|-------------|-----------|--------|
| TAKE-01 | A paired device shows every display of the computer, and one of them alone, enlarged and filling its screen | M001 | built, not yet tried on a phone |
| TAKE-02 | A device sees the screens only after it was allowed to at the computer; off for a new device; taken back within seconds | M001 | built |
| TAKE-03 | The computer shows while a device is looking, and writes each start and end to its log | M001 | built |
| TAKE-04 | Usable on mobile data: a still display costs nothing, a small change costs a few kilobytes | M001 | built, measured on one machine |
| TAKE-05 | A paired device moves the pointer, clicks, scrolls and types on the computer, under a permission of its own | M001 | built; pointer and one key checked on one machine, clicks and typing not yet |
| TAKE-06 | Touch input that suits a phone: trackpad mode, direct touch when enlarged, the phone's keyboard and dictation | M001 | built, not yet tried on a phone |
| TAKE-07 | The screens on macOS and Linux | M001 | pending |
| SEC-01 | What a device may do is given device by device, for a time or until taken back; a device can be set to only watch | M001 | built |
| SEC-02 | A device's token is replaced daily; a replaced token shown again ends the pairing | M001 | built |
| SEC-03 | Other devices can be answered at the secure (TLS) address only | M001 | built, not yet tried with the secure address on |
| SEC-04 | The remote page runs only its own script, named by its SHA-256 | M001 | built |
